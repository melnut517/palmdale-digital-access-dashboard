# Questions for the City of Palmdale

The City's website runs on **CivicPlus**. These questions decide where the dashboard lives and who keeps it current.

## Hosting (ask Communications and/or IT)

1. **Who manages the city website, and can we meet with them for 20 minutes?**
2. **Which do you prefer?**
   - **(a) Link out:** a button or page on cityofpalmdaleca.gov that links to the dashboard hosted on GitHub Pages. *Simplest, and nothing for IT to install.*
   - **(b) City web address:** the dashboard at an address like `digitalaccess.cityofpalmdaleca.gov`. *IT adds one DNS record; hosting stays on GitHub Pages.*
   - **(c) Embed:** the dashboard shown inside a CivicPlus page (an iframe). *Does your CivicPlus setup allow iframes from outside sites?*
   - **(d) City-hosted:** IT puts the files on a City server. *Any standard web server works; no database is needed.*
3. **Are there policies on third-party hosting** (GitHub), on loading Google Fonts, or on analytics/cookies? *The dashboard has no tracking and stores no personal data.*
4. **Does the City already have a GitHub account or organization?** If not, who should own one long-term? Ideally a department role account, not one person.

## Maintenance

5. **Who will update strategy status, and how often** (monthly, quarterly, before council meetings)?
6. **Does an update need approval before it goes live?** If so, from whom?
7. **Who gives us status for each strategy now?** Is there a department lead for each goal?

## Content and branding

8. **Can we use the official City seal/logo?** Please send a high-resolution file (PNG or SVG) and any usage guidelines.
9. **Who should review the Spanish translation?** (Do you have a city translator or a bilingual staff reviewer?)
10. **Where should "Read the full study" link?** (Is the PDF already posted on the City site?)
11. **Which contact email should residents use for questions?**

## Funding (for the funding section)

12. **What digital access funding has the City secured or applied for since July 2025**, and is any of it confidential until awarded?
13. **Should the dashboard show applications in progress**, or only awarded funds?

## Accessibility

14. **Does the City have an accessibility review process or tool** we should run before launch? The dashboard targets WCAG 2.1 AA, the standard the ADA Title II web rule requires of cities Palmdale's size.
